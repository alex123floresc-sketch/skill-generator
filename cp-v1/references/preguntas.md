# Banco de preguntas (Paso 4)

Máximo 5 por ronda. Elige solo las que el pedido no responde y que cambian cómo se construye la skill. Ofrece opciones cuando sea posible para que el usuario responda rápido.

## Preguntas base (casi siempre)

1. **Objetivo:** ¿Qué debe existir o lograrse cuando el proyecto esté terminado?
2. **Entregable:** ¿En qué formato se entrega? (código en repo, web publicada, documento, Excel, presentación, informe impreso…)
3. **Herramientas obligatorias:** ¿Hay tecnologías, programas o formatos que debas usar sí o sí?
4. **Restricciones:** ¿Plazo, normas de la institución, rúbrica, límite de páginas, presupuesto?
5. **Autonomía:** ¿Prefieres que avance y te muestre resultados, o que te consulte antes de cada paso importante?

## Por intención

**Desarrollar**
- ¿Quién usará el resultado y desde qué dispositivo?
- ¿Necesita base de datos, inicio de sesión o publicarse en internet?
- ¿Hay un diseño o ejemplo de referencia?

**Complementar**
- ¿Dónde está lo existente? (archivo adjunto, repositorio, enlace)
- ¿Qué está mal o qué falta exactamente?
- ¿Hay partes que no se deben tocar?

**Gestionar**
- ¿Cuántas personas participan y qué rol tiene cada una?
- ¿Cada cuánto quieres reportes de avance y en qué formato?
- (Datos) ¿De dónde vienen los datos y qué resultado necesitas: tabla, gráfico, conclusión?

**Administrar**
- ¿Qué sistema o recurso se administra y quién más tiene acceso?
- ¿Qué tareas se repiten y con qué frecuencia?
- ¿Existe respaldo actual? ¿Qué acciones requieren tu aprobación siempre?

## Para reutilización

- ¿Este proyecto es nuevo o continúa uno anterior?
- ¿Quieres que la skill sirva para proyectos futuros parecidos (más general) o solo para este (más específica)?

## Para publicación (Punto de control 2)

- ¿Publico en el repositorio de skills de siempre o en otro?
- ¿Público o privado?
- ¿Hay algo del proyecto que no deba aparecer en la skill?
